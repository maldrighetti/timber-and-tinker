# About

Timber & Tinker is a free collection of wood projects for kids and families. The plans are inspired by Leonardo da Vinci: simple machines and clever structures you can build from hardware-store wood, then take outside.

The aim is to get kids outdoors, teach real building skills, and make time to build together.

## Open source

The project lives on GitHub: [maldrighetti/timber-and-tinker](https://github.com/maldrighetti/timber-and-tinker).

Michael Aldrighetti publishes the plans. He does not use GitHub himself. To fix a mistake, improve a page, or add a project, open an issue or a pull request on that repository.

## Add a project

Create a new folder under `projects/` in the repository. Put a `PROJECT.md` file in it, plus the PNG drawings that file names. Picture lines in that file become the drawings on the page.

A `project.json` file in the same folder is optional. It sets the order on the home page, holds a YouTube link for “Watch the build,” and lists parts that can later point at shop links. The repository README has the fields.

When a change is merged into `main`, GitHub Pages publishes the site.
